# archery-timer

M5StickC で動作するアーチェリーの行射タイマーです。本体を **横に倒した状態（横画面）** で使い、
モルテン ハンディータイマーアウトドア **UD0040** を RS-485 で駆動します。

`old_python/snd_data.py` の `--timer` モードを M5StickC に移植したもので、
状態遷移・合図の回数・送出フレームはすべて Python 版と同一です。

```
待機 --[A]--> ムーブアップ 10秒(赤) --> 行射 180秒(緑 / 残り30秒で黄) --> 行射終了(赤)
```

## 構成

| ファイル | 内容 |
| --- | --- |
| `ArcheryTimer/ArcheryTimer.ino` | M5StickC 用スケッチ |
| `platformio.ini` | PlatformIO でビルドする場合の設定 |
| `old_python/` | 元の PC 用プログラム（プロトコル解析・送受信） |

## 操作

Python 版のキー割り当てを、M5StickC の2つのボタンに割り付けています。

| ボタン | Python版 | 動作 |
| --- | --- | --- |
| A（正面の M5）短押し | Space | 開始 / 再開 |
| A 長押し（0.8秒） | 右矢印 | 早送り（この立を終わりにして次へ） |
| B（側面）短押し | Enter | 中断（5声）。**待機中は繰り返し回数の変更** |
| B 長押し（0.8秒） | — | **中断中に待機へ戻す** |

対応する状態以外でボタンを押しても何も起きないところまで Python 版と同じです。

- 中断（行射中）から A で再開すると、時間は止まったところから続きます（1声）。
- 中断（ムーブアップ中）から A を押すと、ムーブアップの最初に戻ります（無音）。
- 中断中に B を長押しすると、どちらの中断からでも待機に戻ります（無音）。繰り返し回数の設定は残ります。
- 行射終了から A を押すと待機に戻り、立も1に戻ります（無音）。

### 繰り返し回数（立）の設定

待機（STANDBY）中に B を短押しするたびに、繰り返す「立」の数が切り替わります。

```
1 → 2 → 3 → 4 → ∞ → 1 → ...
```

設定できる状態であることが分かるように、待機中は上段右の分母だけが点滅します。

`∞` は無制限です。行射終了にならず、何立でも続きます。分子は実際に行った立の数なので、`5/∞` は「5立目」を意味します。止めるときは B（中断）→ B 長押し（待機へ戻す）です。

起動時の値は `REPEAT_DEFAULT`、B で回せる上限は `REPEAT_MAX` で変えられます。

## 画面

画面全体が信号の色になります（遠くからでも状態が分かるようにするため）。

| 状態 | 画面の色 | 文字 | 表示 |
| --- | --- | --- | --- |
| STANDBY（待機） | 赤 | 白 | ムーブアップの秒数 (10) |
| MOVE UP（ムーブアップ） | 赤 | 白 | 残り秒数 10→0 |
| SHOOTING（行射） | 緑 | 白 | 残り秒数 180→31 |
| SHOOTING（残り30秒以下） | 黄 | 黒 | 残り秒数 30→0 |
| HALT（中断） | 赤 | 白 | 中断した瞬間の値 |
| FINISHED（行射終了） | 赤 | 白 | 0（点滅） |

上段左に状態、上段右に「立」（`2/3`、`5/∞` など）、下段に残時間バーを表示します。
合図が鳴っている間は画面に枠が出ます。待機中は「立」の分母が点滅し、B で変更できることを示します。

`∞` はフォントに無いので、円を2つ並べて自前で描いています。

中央の数字は、RS-485 で UD0040 に送っている値と常に同じです。

数字の大きさは、上段と下段を除いた中央の帯に、そのフェーズの最大値が収まる範囲で自動的に最大のフォントが選ばれます。桁が減っても大きさは変わりません。

| 画面 | 中央の帯 | 行射 (180) の数字 |
| --- | --- | --- |
| M5StickC 160x80 | 52 px | 81x48 px |
| M5StickC Plus 240x135 | 107 px | 192x96 px |

緑は白文字が読めるよう、原色より濃い `#009946` にしてあります。色を変える場合は `COLOR_RED` / `COLOR_GREEN` / `COLOR_YELLOW` を書き換えてください。

画面が暗い場合は `SCREEN_BRIGHT` を確認してください。M5StickC ライブラリの `ScreenBreath()` は 7〜12 で 12 が最大ですが、0〜100 を取るライブラリもあり、その場合は `100` を指定します。

## 合図（ブザー）

「0.7秒鳴動 → 0.3秒インターバル」を繰り返す点まで Python 版と同じで、回数だけ場面ごとに違います。

| タイミング | 回数 |
| --- | --- |
| ムーブアップ開始 | 2声 |
| 行射開始 / 再開 | 1声 |
| 早送り・全ラウンド終了 | 3声 |
| 中断（ボタンB） | 5声 |

鳴らすのは UD0040 のブザーです。`BUZZER_KIND_SEL` を `0` にすると止まります
（`0` にしても、合図の「タイミング」自体は画面の枠と0秒の点滅として残ります）。

M5StickC 本体からも鳴らしたい場合は `BUZZER_PIN` にピン番号を指定してください（既定は `-1` = 鳴らさない）。

| 機種 | 設定 |
| --- | --- |
| 無印 M5StickC | 内蔵ブザーが無いので、SPK HAT などを繋いだピン（例: `26`）を指定 |
| M5StickC Plus | 内蔵ブザーが G2 にあるので `2` を指定 |

M5StickC ライブラリには `M5.Beep` が無いため、ledc を直接使っています。
ESP32 Arduino core は 2.x と 3.x のどちらでもビルドできます。

## 設定の変更

`ArcheryTimer/ArcheryTimer.ino` の先頭にある定数を書き換えてください。

```cpp
static const uint16_t MOVEUP_SEC   = 10;   // ムーブアップ（準備）時間 [秒]
static const uint16_t SHOOTING_SEC = 180;  // 行射時間 [秒]
static const uint16_t WARN_SEC     = 30;   // 行射残りこの秒数から黄色 [秒]
static const uint16_t REPEAT_DEFAULT = 1;  // 起動時の繰り返し回数 (0 = ∞)
static const uint16_t REPEAT_MAX     = 4;  // ボタンBで回せる上限 (この次が ∞)
```

3射（120秒）や6射（240秒）にする場合は `SHOOTING_SEC` を書き換えます。
画面の向きが上下逆の場合は `SCREEN_ROTATION` を `3` から `1` に変更してください。

## 配線

M5StickC の Grove 端子に RS-485 ユニットを接続します。

| M5StickC | 用途 |
| --- | --- |
| G32 | TX（`RS485_TX_PIN`） |
| G33 | RX（`RS485_RX_PIN`） |

送信しかしないので RX は使いませんが、逆に繋がっている場合は
`RS485_RX_PIN` と `RS485_TX_PIN` を入れ替えてください。
送受信の切り替え（DE/RE）が自動のユニットを想定しています。手動制御が必要な
ユニットの場合は、`sendDisplay()` / `sendBuzzer()` / `sendInit()` の前後で
DE ピンを操作する処理を足してください。

通信設定は仕様どおり固定です。

```
EIA RS-485準拠 / 半二重 / 調歩同期 / 9600bps / スタート1 / データ8 / パリティ無 / ストップ1
```

## 送出しているフレーム

```
STX(0x02) + 本体を16進にしたASCII文字列 + ETX(0x03) + BCC 2文字
  BCC = XOR(STXの次 〜 ETXまで、ETXを含む) を2桁の大文字16進にしたもの
```

| 本体 | 内容 | 全長 |
| --- | --- | --- |
| `0E 00 01` | 送信開始の宣言（起動時に1回） | 10バイト |
| `01 [7セグ7桁] [区切り] 00 00 00 [得点] 00` | 表示更新（85ms 周期で常時） | 32バイト |
| `0D 00 01 [音種] 00 00` | ブザー鳴動（鳴っている間だけ） | 16バイト |

タイマーは区切り（コロン）を使わない数字表示を使うので、180秒は `3.00` ではなく `180` と出ます。

## ビルド

### Arduino IDE

1. ボードマネージャで `esp32` を追加
2. ライブラリマネージャで `M5StickC` をインストール
3. ボードに `M5Stick-C` を選択
4. `ArcheryTimer/ArcheryTimer.ino` を開いて書き込み

### PlatformIO

```sh
pio run -t upload
```

### M5StickC Plus の場合

スケッチ冒頭の include を入れ替えてください。画面サイズに合わせて
レイアウトとフォントは自動で調整されます。

```cpp
// #include <M5StickC.h>
#include <M5StickCPlus.h>
```
