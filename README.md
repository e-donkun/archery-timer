# archery-timer

M5StickC で動作するアーチェリーの行射タイマーです。本体を **横に倒した状態（横画面）** で使い、
モルテン ハンディータイマーアウトドア **UD0040** を RS-485 で駆動します。

`old_python/snd_data.py` の `--timer` モードを M5StickC に移植したもので、
合図の回数・送出フレームは Python 版と同一です
（設定(SETUP)画面と初期画面は M5StickC 版で追加したものです）。

```
初期画面(赤) --[A]--> ムーブアップ 10秒(赤) --> 行射(緑 / 残り30秒で黄)
    --> (次の立 または 行射終了(赤)) --> 初期画面に戻る
```

**起動すると `Shooting` の先頭（180秒）・`1 / 1` の初期画面から始まります。**
初期画面で **B を押すと設定(SETUP)画面**（黒）に入ります。

## 構成

| ファイル | 内容 |
| --- | --- |
| `ArcheryTimer/ArcheryTimer.ino` | M5StickC 用スケッチ |
| `platformio.ini` | PlatformIO でビルドする場合の設定 |
| `old_python/` | 元の PC 用プログラム（プロトコル解析・送受信） |

## 操作

M5StickC の2つのボタンで操作します。**A は進める、B は移る**、と覚えてください。

| 画面 | A 短押し | A 長押し（0.8秒） | B 短押し | B 長押し（0.8秒） |
| --- | --- | --- | --- | --- |
| 初期画面 | `START`（ムーブアップ開始・2声） | 同左 | SETUP 画面へ | 初期画面のまま |
| SETUP（黒） | カーソルの項目を進める | **初期画面へ** | カーソルを次の項目へ | **初期画面へ** |
| ムーブアップ（赤） | — | 早送り（この立を終わりにして次へ） | 中断（5声） | **初期画面へ** |
| 行射（緑/黄） | — | 早送り | 中断（5声） | 中断（5声） |
| 中断（赤） | `START` / `RESUME` | 同左 | — | **初期画面へ** |
| 行射終了（赤） | 初期画面へ | 同左 | — | **初期画面へ** |

- 画面の右下には、**A を押すとどうなるか**（`START` / `RESUME` / `REPEAT>>` / `MODE>>` / `TIME>>` / `Enter`）が白地のボタンの形で出ます。
- 初期画面の左上にある白い `SETUP` の札は、**B を押すと SETUP 画面に入る** という意味です。
- 中断（行射中）から A で再開すると、時間は止まったところから続きます（1声、ボタンは `RESUME`）。
- 中断（ムーブアップ中）から A を押すと、**ムーブアップの最初から**やり直します（2声、ボタンは `START`）。
- 行射終了は 0 が点滅し、点滅が終わると **自動で初期画面に戻ります**（立も1に戻ります）。

## 設定(SETUP)画面

初期画面で B を押すと入ります。黒地に白文字で、**B でカーソルが下に移り、A でその項目が進みます**。
カーソルのある項目は黄色で点滅します。

```
 [SETUP]   REPEAT: 1 / [ 1 ]
MODE
 Shooting   MakeUp   ShootOff       ← 選んでいるものを枠で囲む
TIME [ 180 ] sec
[ Exit SETUP ]
                        [ TIME>> ]  ← A を押すとどうなるか
```

| カーソル | A を押すと | 右下のボタン |
| --- | --- | --- |
| `REPEAT` | 繰り返す「立」の数が `1 → 2 → 3 → 4 → ∞ → 1 → …` と変わる | `REPEAT>>` |
| `MODE` | `Shooting → MakeUp → ShootOff → Shooting` と変わる | `MODE>>` |
| `TIME` | その MODE の行射時間が表の順に変わる | `TIME>>` |
| `[ Exit SETUP ]` | 設定を終えて初期画面に戻る | `Enter` |

- カーソルは `REPEAT → MODE → TIME → Exit → REPEAT → …` と一周します。
- A・B のどちらでも、**長押しすれば設定を終えて初期画面に戻ります**。
- **`MakeUp` と `ShootOff` は必ず1立だけ**です。`REPEAT` は `1 / [ 1 ]` の固定表示で、A を押しても変わりません。`Shooting` で決めた回数はそのまま残っています。
- 行射時間は MODE ごとに覚えているので、行き来しても戻りません。
- `TIME` の数字の枠は3桁ぶんで固定してあるので、桁が変わっても `[ ] sec` の位置は動きません。

行射時間の並びは表で決めています。`MakeUp` と `ShootOff` は同じ表を使います（選んでいる位置は別々）。

| MODE | 行射時間の並び |
| --- | --- |
| `Shooting` | 180 → 240 → 60 → 90 → 120 → 180 → … |
| `MakeUp` / `ShootOff` | 30 → 40 → 60 → 80 → 90 → 100 → 120 → 150 → 20 → 30 → … |

```cpp
static const uint16_t SHOOTING_SEC_TABLE[] = {180, 240, 60, 90, 120};
static const uint16_t MAKEUP_SEC_TABLE[]   = {30, 40, 60, 80, 90, 100, 120, 150, 20};
```

`∞` は無制限です。行射終了にならず、何立でも続きます。分子は実際に行った立の数なので、`5/∞` は「5立目」を意味します。
止めるときは B（中断）→ B 長押し（初期画面へ）です。

## 画面

画面全体が信号の色になります（遠くからでも状態が分かるようにするため）。

| 状態 | 画面の色 | 文字 | 中央 | 上段左 | 上段右 | 下段 |
| --- | --- | --- | --- | --- | --- | --- |
| 初期画面 | 赤 | 白 | `0` | `SETUP` の札 | 立 or MODE 名 | 行射時間 / `START` |
| SETUP | 黒 | 白 | — | `SETUP` の札 | `REPEAT: 1 / [ 1 ]` | `[ Exit SETUP ]` / A の行き先 |
| MOVE UP | 赤 | 白 | 残り秒数 10→0 | `MOVE UP` | 立 or MODE 名 | 行射時間 |
| 行射 | 緑 | 白 | 残り秒数 | — | 立 or MODE 名 | 残時間バー |
| 行射（残り30秒以下） | 黄 | 黒 | 残り秒数 30→0 | — | 立 or MODE 名 | 残時間バー |
| HALT（中断） | 赤 | 白 | 中断した瞬間の値 | `HALT` | 立 or MODE 名 | 行射時間 / `START`・`RESUME` |
| FINISHED（行射終了） | 赤 | 白 | `0`（点滅） | `FINISHED` | 立 or MODE 名 | — |

上段右は、`Shooting` のときは「立」（`2/3`、`5/∞` など）、`MakeUp` / `ShootOff` のときは
`MAKE UP` / `SHOOT OFF` と出るので、どの MODE で動いているのか分かります。

中央の数字の位置は、右下のボタンの有無で変わりません。行射終了では、0 の点滅が終わってから
（＝初期画面に戻るときに）ボタンが出ます。合図が鳴っている間は画面に枠が出ます。

`∞` はフォントに無いので、円を2つ並べて自前で描いています。

中央の数字は、RS-485 で UD0040 に送っている値と常に同じです。

数字の大きさは、上段と下段を除いた中央の帯に、そのフェーズの最大値が収まる範囲で自動的に最大のフォントが選ばれます。桁が減っても大きさは変わりません。

| 画面 | 中央の帯 | 行射 (180) の数字 |
| --- | --- | --- |
| M5StickC 160x80 | 52 px | 81x48 px |
| M5StickC Plus 240x135 | 107 px | 192x96 px |

緑は白文字が読めるよう、原色より濃い `#009946` にしてあります。色を変える場合は `COLOR_RED` / `COLOR_GREEN` / `COLOR_YELLOW` を書き換えてください。

画面が暗い場合は `SCREEN_BRIGHT` を確認してください。M5StickC ライブラリの `ScreenBreath()` は 7〜12 で 12 が最大ですが、0〜100 を取るライブラリもあり、その場合は `100` を指定します。

## 合図（ブザー）

「0.7秒鳴動 → 0.3秒インターバル」を繰り返す点まで Python 版と同じで、回数だけ場面ごとに違います。

| タイミング | 回数 |
| --- | --- |
| ムーブアップ開始 | 2声 |
| 行射開始 / 再開 | 1声 |
| 早送り・全ラウンド終了 | 3声 |
| 中断（ボタンB） | 5声 |

合図の間は、画面に白い枠が出るのと同時に **本体の赤色LED（G10）** も点きます。
使わない場合は `LED_PIN` を `-1` にしてください。

鳴らすのは UD0040 のブザーです。`BUZZER_KIND_SEL` を `0` にすると止まります
（`0` にしても、合図の「タイミング」自体は画面の枠と0秒の点滅として残ります）。

M5StickC 本体からも鳴らしたい場合は `BUZZER_PIN` にピン番号を指定してください（既定は `-1` = 鳴らさない）。

| 機種 | 設定 |
| --- | --- |
| 無印 M5StickC | 内蔵ブザーが無いので、繋いだブザーのピンを指定。RS-485 HAT で HAT 端子（`0` / `26`）が埋まっているので別のピンにする |
| M5StickC Plus | 内蔵ブザーが G2 にあるので `2` を指定 |

M5StickC ライブラリには `M5.Beep` が無いため、ledc を直接使っています。
ESP32 Arduino core は 2.x と 3.x のどちらでもビルドできます。

## 設定の変更

`ArcheryTimer/ArcheryTimer.ino` の先頭にある定数を書き換えてください。

```cpp
static const uint16_t MOVEUP_SEC   = 10;   // ムーブアップ（準備）時間 [秒]
static const uint16_t WARN_SEC     = 30;   // 行射残りこの秒数から黄色 [秒]
static const uint16_t REPEAT_DEFAULT = 1;  // 起動時の繰り返し回数 (0 = ∞)
static const uint16_t REPEAT_MAX     = 4;  // REPEAT で回せる上限 (この次が ∞)
// 行射時間 [秒]。先頭が起動時の値
static const uint16_t SHOOTING_SEC_TABLE[] = {180, 240, 60, 90, 120};
static const uint16_t MAKEUP_SEC_TABLE[]   = {30, 40, 60, 80, 90, 100, 120, 150, 20};
```

行射時間は SETUP 画面の `TIME` で選べます。並びを変えたい場合はこの表を書き換えてください
（個数はいくつでも構いません）。MODE そのものを増やしたい場合は `MODES` に1行足します。
画面の向きが上下逆の場合は `SCREEN_ROTATION` を `3` から `1` に変更してください。

## 配線

M5StickC の底面 HAT 端子に **RS-485 HAT** を挿します。

| M5StickC | 用途 |
| --- | --- |
| G0 | TX（`RS485_TX_PIN`） |
| G26 | RX（`RS485_RX_PIN`） |

M5StickC ライブラリの `examples/Hat/RS485`（`Serial2.begin(..., 26, 0)`）と同じ割り当てです。
送信しかしないので RX は使いません。

Grove 端子の RS-485 ユニットを使う場合は、`RS485_TX_PIN` を `32`、`RS485_RX_PIN` を `33`
に戻してください（逆に繋がっている場合も入れ替えます）。

G0 は起動モードを決めるピンでもありますが、送信側（ESP32 の出力）なので、
HAT を挿したままでも通常どおり起動します。
送受信の切り替え（DE/RE）が自動のユニットを想定しています。手動制御が必要な
ユニットの場合は、`sendDisplay()` / `sendBuzzer()` / `sendInit()` の前後で
DE ピンを操作する処理を足してください。

通信設定は仕様どおり固定です。

```
EIA RS-485準拠 / 半二重 / 調歩同期 / 9600bps / スタート1 / データ8 / パリティ無 / ストップ1
```

## 送出しているフレーム

```
STX(0x02) + 本体を16進にしたASCII文字列 + ETX(0x03) + BCC 2文字
  BCC = XOR(STXの次 〜 ETXまで、ETXを含む) を2桁の大文字16進にしたもの
```

| 本体 | 内容 | 全長 |
| --- | --- | --- |
| `0E 00 01` | 送信開始の宣言（起動時と、表示が変わるたび＋1秒ごと） | 10バイト |
| `01 [7セグ7桁] [区切り] 00 00 00 [得点] 00` | 表示更新（85ms 周期で常時） | 32バイト |
| `0D 00 01 [音種] 00 00` | ブザー鳴動（鳴っている間だけ） | 16バイト |

タイマーは区切り（コロン）を使わない数字表示を使うので、180秒は `3.00` ではなく `180` と出ます。

タイマーは送信開始の宣言を受け取るまで受信モードにならないので、起動時だけでなく
**表示が変わるたび**（秒が変わる、消灯に切り替わる、設定の秒数を変える）と、
**表示が止まっていても1秒ごと**に、表示更新の直前へ宣言を挟んでいます。
途中でケーブルが抜けても、挿し直せば1秒以内に受信モードに戻ります。

出し直す間隔は `INIT_RESEND_MS` で変えられます。

## ビルド

### Arduino IDE

1. ボードマネージャで `esp32` を追加
2. ライブラリマネージャで `M5StickC` をインストール
3. ボードに `M5Stick-C` を選択
4. `ArcheryTimer/ArcheryTimer.ino` を開いて書き込み

### PlatformIO

```sh
pio run -t upload
```

### M5StickC Plus の場合

スケッチ冒頭の include を入れ替えてください。画面サイズに合わせて
レイアウトとフォントは自動で調整されます。

```cpp
// #include <M5StickC.h>
#include <M5StickCPlus.h>
```
