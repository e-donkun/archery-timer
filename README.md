# archery-timer

M5StickC で動作するアーチェリーの行射タイマーです。本体を **横に倒した状態（横画面）** で使い、
モルテン ハンディータイマーアウトドア **UD0040** を RS-485 で駆動します。

`old_python/snd_data.py` の `--timer` モードを M5StickC に移植したもので、
合図の回数・送出フレームは Python 版と同一です
（設定(SETUP)画面と初期画面は M5StickC 版で追加したものです）。

```
初期画面(赤) --[A]--> ムーブアップ 10秒(赤) --> 行射(緑 / 残り30秒で黄)
    --> (次の立 または 行射終了(赤)) --> 初期画面に戻る
```

**起動すると `Shooting` の先頭（180秒）・`1 / 1` の初期画面から始まります。**
初期画面で **B を押すと設定(SETUP)画面**（黒）に入ります。

## シミュレータ

`simulator/ArcheryTimer.html` をブラウザで開くと、実機なしで動きを確かめられます。
HTML 1ファイルだけで動くので、ダブルクリックで開くだけです（通信もインストールも不要）。

- 画面の A / B をクリック（キーボードは <kbd>A</kbd> / <kbd>B</kbd>、または <kbd>→</kbd> / <kbd>←</kbd>）。**0.8秒押し続けると長押し**になります。
- 合図の間は、実機と同じように画面に白い枠が出て、左下の赤色LEDが点きます。
- **ブザーは既定でOFF**です。チェックを入れると鳴ります（3450Hz の正弦波を 18Hz で振幅変調した、モルテンの「ピロピロ…」に寄せた音）。
- 「早回し」にすると10倍速で進むので、180秒の行射も18秒で確認できます。
- 状態遷移・画面レイアウトはスケッチと同じもので、RS-485 の送出だけ行いません。

操作の詳しい内容は [docs/操作方法.md](docs/操作方法.md) を参照してください。

## ビルド

### Arduino IDE

1. ボードマネージャで `esp32` を追加
2. ライブラリマネージャで `M5StickC` をインストール
3. ボードに `M5Stick-C` を選択
4. `ArcheryTimer/ArcheryTimer.ino` を開いて書き込み

### PlatformIO

```sh
pio run -t upload
```

### M5StickC Plus の場合

スケッチ冒頭の include を入れ替えてください。画面サイズに合わせて
レイアウトとフォントは自動で調整されます。

```cpp
// #include <M5StickC.h>
#include <M5StickCPlus.h>
```

配線・通信の詳しい仕様は [docs/信号仕様.md](docs/信号仕様.md)、
ボタン操作や画面の見方は [docs/操作方法.md](docs/操作方法.md) を参照してください。
